# Delivery Roadmap

## Current Strategy

Initialize delivery-control without renaming historical indexes or legacy labels.
The project has active parallel streams; `UI-1D` is allowed as the next UI slice,
but it must be selected with explicit dependencies on Runner, Observer, Genome,
Core, Bootstrap, and Stability status.

## Historical Evidence

Historical worklog-derived rows live in `docs/delivery/worklog-ledger.md`. They are evidence only, not canonical requirements or active roadmap items.

## Slice Dependency Rule

Child slices are the unit for `roadmap-control` selection and TDD planning.
`Dependencies` are blocking unless explicitly marked `soft`. A `done` worklog
without closure matrix starts as `done-weak-evidence` until coverage is checked.
